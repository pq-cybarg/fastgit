Architecture Highlights

🔐 Hash-Agile OIDs

Variable-length OIDs (20/32/48/64 bytes) for SHA-1, SHA-256, SHA-384, SHA-3-512. Automatic detection via hex length. Index, pack, MIDX, and ODB all support dynamic hash lengths. Migration tool converts SHA-1 repos to SHA-256 in-place.

⚡ Baremetal Optimizations

io_uring (Linux) / kqueue (macOS) / IOCP (Windows) async I/O with linked SQEs for WRITE+FSYNC. Thread pool with pending/done condvars. SIMD-accelerated CRC32, memcpy, SHA-256 (NEON/AVX2). Arena allocator for zero-overhead allocations.

📦 Pack v2 + MIDX + Delta

Full Git-compatible pack v2 (PACK 0x5041434b ver2), varint type/size, OFS_DELTA ((off+1)<<7), REF_DELTA (32-byte), zlib inflate, Git delta 0x80 copy/insert. MIDX v1 with 32-byte OID fanout. Parallel pack batch (8 workers) with single dir fsync.

🌐 Smart HTTP/SSH + Resilience

libcurl + libssh transports. Pkt-line parsing (40/64-char OIDs, 0000/0001). Retry-After/JWT token cache. Circuit breaker (5 failures → 30s open). Load shedding (64 concurrent, 256 queue, 90% shed). Exponential backoff + jitter. Budget: 20 retries/min.

🔄 Full Git Parity (38 Verbs)

init, clone, add, commit, status, diff, log, checkout, branch, merge, rebase, fetch, push, pull, remote, tag, reset, rm, mv, stash, show, blame, grep, ls-files, ls-tree, cat-file, hash-object, write-tree, read-tree, commit-tree, update-index, config, benchmark, stats, doctor, migrate, verify, version

🛡️ Crash-Safe Durability

Index lockfile (path.lock + fsync + atomic rename). ODB tmp. + O_EXCL + fsync + rename + dir fsync. Reflog width = oid_len*2. Pack SHA-256 trailer + idx SHA-256 checksum. Refs written atomically.

Quick Start

# Build (requires cmake, openssl, zlib, curl, libssh) cmake -S . -B build -DFASTGIT_ENABLE_WERROR=OFF -DFASTGIT_NATIVE_OPT=OFF cmake --build build -j$(nproc) # Run tests ctest --test-dir build # Use fastgit (Git-compatible CLI) ./build/src/fastgit-cli init myrepo cd myrepo echo "hello" > file.txt ./build/src/fastgit-cli add . ./build/src/fastgit-cli commit -m "first commit" ./build/src/fastgit-cli log --oneline

Interoperability with Git

# fastgit creates Git-compatible SHA-256 repos ./build/src/fastgit-cli init --bare repo.git cd repo.git # git interop works (Git 2.42+ with extensions.objectFormat=sha256) git -c extensions.objectFormat=sha256 clone repo.git worktree # Or use fastgit directly ./build/src/fastgit-cli hash-object -w ../file.txt git cat-file -p $(./build/src/fastgit-cli hash-object ../file.txt)
